# Lab Procedure Framework — UI Prototype

Small vanilla HTML/CSS/JavaScript prototype for the proposed modular asphalt laboratory application.

## Files

- `index.html` — application shell and placeholder module
- `style.css` — layout and visual styling
- `app.js` — view switching, placeholder calculation, navigation behavior

## Current prototype

- Persistent left navigation tree
- Placeholder installed modules
- Example procedure module
- Perform / Calculate / Reference views
- Small prism visual that rotates between the three views
- Page-style transition between views
- Minimal live calculation demonstrating value propagation

No real asphalt procedure logic is implemented yet.
